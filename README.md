## What it does

`main.py` (Python 3, standard library only) writes exactly one funny line — a single joke that lands on a cold read — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
